# Tech Stack

## Frontend

- **Framework**: Next.js 16.1.5
- **UI Library**: React 19.2.3
- **Styling**: Tailwind CSS 4
- **Component Library**: shadcn/ui (built on Radix UI primitives)
- **Icons**: HugeIcons React
- **State Management**: Zustand 5.0.10
- **Data Fetching**: TanStack Query (React Query) 5.90.20
- **Forms**: React Hook Form with Zod validation
- **Type Safety**: TypeScript 5
- **Build Tool**: Next.js built-in bundler

## Backend

**Note**: The backend is an external project (not part of this repository). This repository contains only the frontend application.

- **Runtime**: Node.js
- **Framework**: NestJS
- **Database**: PostgreSQL
- **ORM**: Prisma

## Testing

- **Testing Framework**: Jest
- **Component Testing**: React Testing Library

## Code Quality

- **Linting**: ESLint with Next.js config
- **Formatting**: Prettier
- **Git Hooks**: Husky
- **Pre-commit**: Lint-staged
- **Commit Standards**: Commitlint

## Code Standards

- **Style Guide**: Airbnb JavaScript Style Guide
- **Organization**: Feature-based folder structure
- **Naming Conventions**:
  - Components: PascalCase
  - Functions: camelCase
  - Files: kebab-case

## Development Tools

- **Package Manager**: pnpm (workspace-based)
- **Type Checking**: TypeScript strict mode
- **CSS Processing**: Tailwind CSS with PostCSS
